# Bloomberg Indices

Bloomberg Indices are a comprehensive family of fixed income, equity, commodity, and multi-asset benchmark indices used by institutional investors worldwide. Includes the Global Aggregate Bond Index, US Aggregate Bond Index, Bloomberg Commodity Index (BCOM), and the Bloomberg Galaxy Crypto Index.

## APIs

- **Bloomberg Index Data API** - Constituent data, weights, analytics, and returns
- **Bloomberg Commodity Index (BCOM)** - Commodity futures index data
- **Bloomberg Galaxy Crypto Index** - Cryptocurrency index data
